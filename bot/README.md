# Бот

Telegram-бот клуба «Лапки помощи». Принимает от API события, держит у себя очередь доставки и отправляет сообщения волонтёрам и организаторам на их языке.

## Как работает доставка

1. API публикует событие в топик Kafka `KAFKA_NOTIFICATIONS_TOPIC`: кому (Telegram ID), тип, приоритет, данные и время отправки `send_at` (пусто — сразу).
2. Бот читает топик и **сначала** сохраняет событие в свою очередь (таблица `notification_jobs` в той же PostgreSQL, что и у API), и только потом подтверждает чтение в Kafka. Повторы отбрасываются по `id`.
3. Воркер берёт из очереди готовые к отправке события: сначала высокий приоритет, внутри приоритета — по времени. Между отправками выдерживается пауза, чтобы не упереться в лимиты Telegram.
4. При временной ошибке событие откладывается и повторяется с растущей задержкой, при постоянной (пользователь заблокировал бота) — помечается проваленным.

События с одним `key` (напоминания) заменяют друг друга: новое вытесняет ещё не отправленное прежнее. Отмена мероприятия, отмена записи, отказ по заявке и перенос начала убирают ждущие напоминания об этом мероприятии.

## Языки

Тексты лежат в `src/bot/i18n/locales/<язык>/messages.ftl` в формате [Project Fluent](https://projectfluent.org): в нём есть правила множественного числа и склонения. Сейчас доступны русский (по умолчанию) и английский. Чтобы добавить язык, создайте папку с `messages.ftl` и добавьте код языка в `Translator.SUPPORTED` и `LanguageChoice.NAMES`; тест проверяет, что во всех языках одинаковый набор ключей.

Язык пользователя бот запоминает при `/start` по настройкам Telegram и хранит в таблице `user_locales`. Менять язык можно inline-кнопками (`LanguageChoice.keyboard()` готова для вставки в меню). Даты показываются в часовом поясе `BOT_TIMEZONE`.

## Быстрый старт

```bash
uv sync
cp .env.example .env     # задайте POSTGRES_PASSWORD (как у API) и TELEGRAM_BOT_TOKEN
docker compose --env-file .env -f ../docker-compose.dev.yml up -d db kafka
uv run alembic upgrade head   # у бота своя таблица версий alembic_version_bot
uv run python -m bot
```

## Проверки

uv run ruff check . && uv run ruff format --check .
uv run mypy
