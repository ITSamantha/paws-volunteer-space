# Paw Volunteer Space

Платформа для координации волонтёров клуба «Лапки помощи» ITMO: организация мероприятий, запись волонтёров и посещения приютов.

Монорепозиторий из двух независимых проектов, каждый со своим `pyproject.toml`:

| Каталог | Назначение |
|---|---|
| [backend/](backend/README.md) | API на FastAPI и PostgreSQL |
| `bot/` | Telegram-бот, общается с API по HTTP (появится позже) |

Общее лежит в корне: `docker-compose.dev.yml` и `docs/` (схема БД).
